## 3. المعايير الهندسية والتقنية المحققة (Engineering Quality Gates)

1. **صفر استدعاء خارجي (ZERO CSS @import)**: كافة ملفات التنسيق خالية تماماً من `@import`.
2. **استضافة الخطوط محلياً بنسبة 100%**: تم تحميل خطوط `Cairo` محلياً بصيغة `.woff2` مع تفعيل `font-display: swap` والتحميل المسبق المسبق `preload` لخط العناوين.
3. **تكافؤ القائمة الجانبية على 100% من المسارات الفرعية**: زر قائمة الجوال والدرج الجانبي ومستمعات الأحداث البرمجية تعمل بكفاءة على كافة الصفحات دون أي استثناء.
4. **بنية البيانات المنظمة المتصلة (`@graph`)**: كل صفحة تحتوي على مخطط JSON-LD موحد يربط المنشأة بالخدمات والموقع الجغرافي الدقيق.
5. **مطابقة تصنيف Open Graph**: تم استخدام `og:type="website"` للصفحات التجارية، و `og:type="article"` حصرياً للدليل الفني مع تواريخ ISO-8601.
6. **معيار الجاهزية للاقتباس بالذكاء الاصطناعي (Chunk Readiness)**: كل قسم وعنوان H2/H3 يبدأ بإجابة حاسمة ومباشرة مدعومة بجداول المقاسات والأسعار المعلنة غير المخفية.
7. **سرعة العرض الأولية (LCP)**: تم وسم صور البطل بـ `fetchpriority="high"` و `<link rel="preload">` وأبعاد صريحة `width` و `height` لمنع أي انزياح في التخطيط (CLS = 0.00).

## 4. تعليمات النشر والاستضافة المباشرة (Deployment Instructions)

الموقع جاهز للرفع المباشر على أي منصة استضافة سريعة (مثل Netlify, Vercel, Cloudflare Pages, أو سيرفرات Apache / Nginx):
1. **الرفع المباشر**: رفع محتويات مجلد `projects/sayyafac/website/` إلى المجلد الجذري للخادم (`public_html` أو root).
2. **روابط المجلدات النظيفة**: تدعم جميع المنظمات الحديثة (Netlify / Vercel / Nginx) روابط المجلدات تلقائياً بحيث يظهر الرابط `https://sayyafac.com/installation/` نظيفاً دون الحاجة لكتابة اسم الملف.
3. **شهادة الأمان والتشفير (SSL)**: تفعيل HTTPS مجاني لضمان أمان الاتصال وموثوقية المتصفحات.
